4-Week Development Roadmap
Week 1: Interface Locking & Development Setup
* Joint Task: Define the memory-aligned target_data.h C struct containing target coordinates, confidence score, and timestamp.
* Partner A: Set up CMake repository structure, link OpenCV, and build a video reader that processes synthetic thermal MP4 files frame-by-frame.
* Partner B: Initialize Cargo workspace with tokio and mavlink crates; launch local ArduPilot SITL to verify UDP telemetry reception.
Week 2: Isolated Subsystem Logic
* Partner A: Implement thresholding, contour extraction, and bounding box logic to locate heat targets in video frames; write coordinates to shared memory.
* Partner B: Build POSIX shared memory reading logic in Rust; parse incoming MAVLink GLOBAL_POSITION_INT messages from the simulated drone.
Week 3: System Integration & End-to-End Simulation
* Partner A: Add basic centroid tracking to filter out single-frame false positives and smooth target paths.
* Partner B: Combine target offsets with drone GPS coordinates to calculate absolute target coordinates; broadcast Cursor-on-Target (CoT) or custom MAVLink packets over local network.
* Joint Task: Run a full simulation pass (Video -> C++ SHM -> Rust Engine -> Ground Station Map).
Week 4: Optimization, CI, & Hardware Preparation
* Partner A: Benchmark image processing frame rates and memory footprint to ensure compatibility with low-power ARM board limits.
* Partner B: Implement cross-compilation pipeline (cross for ARM64) and refine error handling for unexpected socket disconnections.
* Joint Task: Set up GitHub Actions CI for automated testing, write comprehensive README documentation with system diagrams, and prepare for physical flight controller connection.
Git Workflow & Team Protocol
* Branch Strategy: Maintain a protected main branch. All feature developments occur on topic branches (e.g., feature/vision-shm-writer or feature/rust-mavlink-udp).
* Pull Request Rule: Require passing CI builds and at least one code review approval from your partner prior to merging.
